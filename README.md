# 旅途密令

一个无需后台的静态网页应用。每台手机独立抽取任务、记录得分和每日复盘；任意一台手机可在“总榜”页汇总大家报出的总分。

## 在线地址

https://yishanwang0430-sketch.github.io/trip-mission/

## 简化规则

1. 每人每天默认最多抽 2 个任务。
2. 任务抽出后只能完成或放弃，2 小时后自动超时。
3. 任务按难度固定为 1、2、3 分。
4. 完成后说“计成”，由一名在场玩家确认。
5. 放弃、超时或越过安全边界均为 0 分。
6. 每日复盘时分享当日记录，全员投票选一个“最佳妙计”加 1 分。
7. 总榜优先按场均分排序，兼顾中途加入或提前离开的玩家。

## 本地运行

在本目录启动任意静态服务器，例如：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 公网发布

本项目通过 GitHub Pages 发布。仓库 `main` 分支更新后，线上网站会自动重新发布。

所有个人记录保存在各自手机浏览器的 `localStorage` 中。更换手机或清除微信浏览器数据前，应在“设置”中导出记录。
